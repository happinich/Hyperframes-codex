# 검수 체크리스트: {{TITLE}}

## 자막 및 음성

- [ ] 녹음이 승인된 `narration.txt`와 단어 단위로 동일하다.
- [ ] `sync_report.json`의 상태가 `ready_for_review`이며 자막을 청취 검수했다.
- [ ] 숫자, 고유명사, 영문 약어의 표시와 발음이 정확하다.

## 화면

- [ ] 본편·쇼츠·썸네일의 모든 이미지를 생성 직후 원본 크기로 개별 확인했다.
- [ ] 렌더 전 모든 선택 이미지를 대본·인접 장면과 대조해 두 번째 시각 검수를 했다.
- [ ] 손·신체·사물 구조와 접촉, 인물·차량·공간 연속성, 등장 시점, 의도하지 않은 얼굴·문자, 모바일 가독성을 확인했다.
- [ ] 오류 또는 불확실한 이미지는 제외·재생성하고 교체본도 두 차례 검수를 통과했다. 미해결 컷은 없다.
- [ ] 이미지 식별자/파일 또는 해시, 두 검수 결과, 오류·재생성 이력과 최종 판정을 `05_review/image-review.md`에 기록했다.
- [ ] 최종 영상의 크롭·확대·모션 적용 후에도 이미지에 문제가 없는지 재확인했다.
- [ ] 얼굴이 노출되는 영상 또는 이미지가 없다.
- [ ] 모든 씬이 `scene-plan.json`의 목적과 일치한다.
- [ ] 공포 본편에는 화면 자막이 없고 업로드용 SRT/VTT가 준비되어 있다. 별도 승인된 자막본이 있다면 하단 안전 영역과 가독성을 추가 검수했다.
- [ ] 자산 사용권과 출처가 확인되었다.

## 공포 프로필

- [ ] 첫 5~10초 콜드 오프닝이 제목·썸네일의 약속을 바로 충족한다.
- [ ] 콜드 훅 뒤 장소에 간 이유와 정상 규칙이 제시되고 첫 이상 징후가 40~60초 사이에 등장한다.
- [ ] 한 영상에서 6~8분 이야기 한 편이 완결된다.
- [ ] 새 대본이 사람이 들려주듯 자연스러운 존댓말 구술형 이야기체이며, 했다·였다 단문이나 한 가지 종결이 반복되지 않는다.
- [ ] 3초 이상 완전 정지와 1초 이상 완전 검정 구간이 없다.
- [ ] 어두운 장면에서도 결정적 단서가 모바일 크기로 읽힌다.
- [ ] 내레이션, 공간 앰비언스, 효과음, BGM이 서로 가리지 않는다.
- [ ] 0.8초가 넘는 의도된 적막이 씬 플랜에 표시되어 있다.
- [ ] 작품 성격이 창작·제보 각색·검증된 경험담 중 하나로 기록되어 있다.
- [ ] 쇼츠 관련 동영상과 롱폼 엔드스크린 연결 대상이 정해졌다.

## 출력

- [ ] YouTube본이 1920x1080, 16:9, 60fps로 렌더되었다.
- [ ] 오디오 peak, 잘림, 무음 구간을 확인했다.
- [ ] 첫 1초 훅이 있고 정체·반전·결말을 공개하지 않는 15~40초 쇼츠 전용 대본을 별도 승인했다.
- [ ] 쇼츠 음성을 별도 생성하고 피치 보존 1.07배 속도를 청취 검수했다.
- [ ] Shorts가 1080x1920, 9:16, 60fps 별도 컴포지션으로 렌더되었다.
- [ ] Shorts 첫 프레임과 첫 음성이 잘리지 않고 동시에 시작한다.
- [ ] Shorts 번인 자막과 외부 SRT/VTT의 타이밍·모바일 안전 영역을 검수했다.
- [ ] `07_publish/shorts/shorts-publish.html`과 본편 관련 동영상 대상이 준비되었다.
