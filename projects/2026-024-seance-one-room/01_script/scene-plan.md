# 강령술 원룸: 초 단위 장면 계획 (원고 승인, 음성 전 예상 시각)

- 콘텐츠: 창작 공포. 한 편 완결, 목표 6~8분.
- 실제 음성: 962어절, 약 469.1초(7분 49초). Whisper 단어 타이밍으로 모든 장면 경계를 재계산했다.
- 승인 프로필: `horror_cinematic_story_v1`. 승인 화면 스타일: `horror_cinematic`. 보이스: Esther 여성 보이스.
- 화면: 얼굴 비노출. 한 화면 3초 초과 정지 금지. 각 이미지에는 1~3초마다 카메라 이동·초점·조명·그림자 중 최소 하나의 의미 있는 변화.
- 낭독과 화면: 단서는 해당 발화 약 0.35초 먼저 준비. 실제 촬영/합성 시 자막 문구는 승인된 `narration.txt`와 동일하게 유지.
- 앰비언스, 사건 효과, BGM은 별도 트랙. BGM은 음성 검수 후 별도 사용자 승인.
- 화면 자막: 본편 기본 미번인, 별도 SRT/VTT. 쇼츠는 새 세로 이미지와 번인 자막.
- 이미지 목표: 본편 약 40~50개의 **고유 생성 이미지**를 씬과 컷으로 분산하고, 씬당 2~3개의 카메라/광원 움직임을 더한다. 생성 후 각 이미지의 원본과 장면 연결을 검수한다.
- 본편 마지막 15~20초는 화면 하단 단서를 유지하되 다음 영상/재생목록 엔드스크린 안전 영역으로 비운다.
