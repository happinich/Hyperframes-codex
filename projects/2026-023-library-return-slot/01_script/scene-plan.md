# 초 단위 씬 계획 (음성 생성 전 추정)

원고 961어절, 130어절/분 가정, 본편 7분 28초 추정. 실제 시간은 승인 후 TTS와 Whisper로 조정. 장면별 최소 2.5초 카메라/조명 변화를 목표로 함.

- s01 0.0~6.5초: 콜드 오픈: 반납함 철문 아래로 접히는 종이 손과 화자의 발목. 발과 손의 접촉은 암부에서도 읽히게.
- s02 6.5~30.0초: 야간 도서관 정경. 책 정리 업무와 파란 카트, 비어 있는 열람실. 화자 얼굴은 프레임 밖.
- s03 30.0~57.2초: 외부 철문-경사판-내부 받침 상자 지리 확립. 파란 카트 도구통의 작은 가위.
- s04 57.2~71.5초: 빈 CCTV 화면과 흔들리는 반납함 철문. 화면 글자·시각 숫자 없음.
- s05 71.5~96.9초: 비어 있던 받침 상자 안에 세워진 표지 없는 책. 책등 대신 접힌 주름.
- s06 96.9~113.5초: 책을 밀어 놓자 페이지 모서리가 조금씩 벌어지는 접사.
- s07 113.5~135.2초: 책이 다시 받침 상자 안에 있고 붉은 천 책갈피가 처음 나타남.
- s08 135.2~150.5초: 경비실 전화, 열린 작업실 문, 문밖 복도와 카트.
- s09 150.5~172.6초: 받침 상자가 들썩이고 종이 끝이 손가락 다섯 개로 접히는 단계별 접사.
- s10 172.6~195.7초: 화자가 파란 카트를 복도로 끌고 나가 방화문을 닫음. 작은 유리창 뒤 손이 책을 떠남.
- s11 195.7~216.5초: 종이 손가락이 방화문 밑을 통과해 복도 바닥에서 다시 세워짐.
- s12 216.5~240.9초: 카트 바퀴가 접힌 손 위를 지나가고 손가락이 바퀴 양옆으로 다시 나옴. 붉은 천이 손목에 감김.
- s13 240.9~265.9초: 방화문 유리 너머 종이 주름으로 된 몸통과 긴 팔, 닫힌 표지 같은 얼굴의 부분 윤곽.
- s14 265.9~288.5초: 문 아래 손과 안쪽 문손잡이 손이 분리되어 움직임. 붉은 천 당김.
- s15 288.5~314.3초: 카트 도구통에서 초반에 본 가위를 꺼냄. 종이 손이 발목을 직접 잡음.
- s16 314.3~330.5초: 붉은 책갈피를 자르고 발을 빼는 물리적 동작. 운동화 옆에 종이 조각 남음.
- s17 330.5~352.6초: 비상계단의 코너를 종이 조각이 먼저 돌아 내려와 길을 막음.
- s18 352.6~371.1초: 아래층 경비와 화자가 만남. 운동화에 붙은 종이 접힘이 보임.
- s19 371.1~392.8초: 벗어 둔 운동화 속에서 종이가 발등 형태로 부풀고 비상문 틈에 끼임.
- s20 392.8~410.3초: 아침 빈 받침 상자와 방화문 아래 붉은 천 조각. 실제 존재의 잔흔.
- s21 410.3~425.1초: 낮 정문 임시 반납함 점검 안내. 글자는 후반 합성으로만 필요한 경우 사용.
- s22 425.1~443.5초: 집 바닥에 놓인 코트 주머니 내부가 미세하게 들썩임. 책장 소리만, 존재 정체를 재노출하지 않음.
