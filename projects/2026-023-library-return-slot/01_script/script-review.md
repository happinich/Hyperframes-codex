# 대본 2차 검수

상태: 기획 원고 검수 완료. 사용자 원고·시각 스타일 승인 전 음성·이미지·합성 미진행.

## 1차 이야기·동선

- 직전 저수지, 헬스장 거울, 세차장, 고시원 등과 공간·반복 물건·위협 형태·탈출 장치를 구분했다. 복제 목소리나 물귀신을 반복하지 않는다.
- 반납함 외부 철문 → 금속 경사판 → 작업실 받침 상자, 작업실 방화문 → 복도 → 비상계단 → 아래층 방화문의 이동을 점검했다.
- 파란 카트와 가위는 초반에 소개하고, 화자가 카트를 복도로 함께 끌고 나가므로 문밖 활용이 가능하다. 붉은 책갈피도 손목에 닿기 전 등장한다.
- 경비는 전화로 올라오겠다고 한 뒤 화자가 아래층에서 만난다. 경비가 위협의 기원이나 만능 해결법을 설명하지 않는다.
- 종이 손은 흔적/부분 노출 → 손가락의 문틈 이동 → 몸 전체의 일부 공개 → 발목 물리적 접촉으로 진행한다. 물리적 실재가 모호하게 끝나지 않는다.
- 탈출은 가위로 천을 끊고 운동화를 벗고 비상문을 닫는 주인공과 경비의 행동이다. 위협을 완전히 제거했다고 주장하지 않는다.

## 2차 낭독·시각 검수

- 961어절, 숫자 없음. 첫 훅은 약 7~8초. 130어절/분 가정 시 첫 철문 이상 소리는 약 58초에 시작한다. 실제 길이는 TTS 후 확정한다.
- `했다/였다` 단문 연속, 화면 설명 메타 멘트, 인사말 없음. 짧은 문장과 긴 호흡을 섞은 자연스러운 존댓말 1인칭 이야기체.
- 인체 형태의 종이 존재는 판타지 의도다. 실제 생성 이미지는 손가락 개수, 마디, 책/몸의 연결, 문틈 방향, 카트와 비상문 위치를 개별적으로 두 차례 검수해야 한다.
- 실제 책 표지 글자, 도서관 명칭, 주민 정보 같은 생성 텍스트는 피한다. 본편은 클린 마스터, 쇼츠는 새 세로 자산과 독립 원고 사용.
- 독립 쇼츠 초안은 빈 책과 붉은 천·접히는 종이까지만 보여주고 존재의 전신·구조 방법·집 주머니 결말을 공개하지 않는다. 쇼츠 원고도 별도 승인 전 TTS를 만들지 않는다.
