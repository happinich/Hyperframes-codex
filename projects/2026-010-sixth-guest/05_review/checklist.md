# 검수 체크리스트: 다섯 명이 체크인했는데 CCTV에는 여섯 명이 찍혔다

## 자막 및 음성

- [x] 녹음이 승인된 `narration.txt`와 단어 단위로 동일하다.
- [x] `sync_report.json`의 상태가 `ready_for_review`이며 자막을 청취 검수했다.
- [x] 숫자, 고유명사, 영문 약어의 표시와 발음이 정확하다.
- [x] Whisper 대본 일치율 97.9%로 최소 기준 92%를 통과했다.
- [x] 평균 음량 -18.6dB, 최대 음량 -3.5dB로 클리핑이 없다.

## 화면

- [x] 얼굴이 노출되는 영상 또는 이미지가 없다.
- [x] 모든 씬이 `scene-plan.json`의 목적과 일치한다.
- [x] 자막이 두 줄 이내이며 하단 안전 영역에 있다.
- [x] 흰색·검정 테두리 기본 자막과 현재 발화 단어의 빨간 강조를 확인했다.
- [x] 생성 이미지와 직접 제작한 그래픽만 사용했다.
- [x] 초반·중반·후반 및 엔딩 프레임에서 글자 잘림과 도형 겹침이 없다.
- [x] 상시 장면 제목과 좌우 하단 정보 박스를 제거한 1분 샘플을 2026-08-15에 승인받아 전체 영상에 반영했다.
- [x] `freezedetect=n=0.003:d=3` 검사에서 3초 이상 정지 구간이 검출되지 않았다.

## 출력

- [x] YouTube본이 1920x1080, 16:9, 60fps로 렌더되었다.
- [x] 클린본 영상 19분 13.033초, 자막본 영상 19분 13.000초, 공통 오디오 19분 13.045초이며 H.264/AAC 스트림이 정상이다.
- [x] 오디오 peak, 잘림, 무음 구간을 확인했다.
- [x] SRT와 VTT 외부 자막 파일을 함께 생성했다.
- [x] 1280x720 썸네일 2종과 복사형 게시 도우미를 생성했다.
- [ ] Shorts 제작 시 세로 배치를 별도 검수했다.
