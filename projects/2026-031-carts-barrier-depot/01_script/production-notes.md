# 031 제작 대기 노트

본편·쇼츠 원고는 2026-10-18 승인됐고, 화면 세 편과 두 화자 보이스가 모두 승인돼 생성·검수 중이다. `narration.txt`와 편별 원고의 일치를 유지한다. 본편 1.00x, 쇼츠 1.07x 후처리, `eleven_v4`를 사용한다. 이야기별 캐스팅 추천은 C01 여성 Jian.K, C02·C03 남성이다. Jian.K 상시 선호는 여성 화자를 선택한 이야기 안에서만 적용한다. 남성 보이스는 이번 대사 샘플 비교 뒤 선정하며 2026-10-18 A · Hyuk이 C02·C03과 해당 쇼츠의 화자로 승인됐다.

씬·숏·모션 시각은 모두 예상값이다. 최종 음성 뒤 `mlx-community/whisper-large-v3-turbo`로 실제 단어 시각을 추출하고 원문을 유지한 채 다시 맞춘다. 부분 공개·접촉·결말의 이미지가 대사보다 먼저 노출되지 않도록 시각 선행 0.35초는 일반 정보 준비에만 적용한다.

카트의 별도 배치, 방음벽 좌측 계단과 우측 끝, 차고지의 표지판 순서는 `scene-plan.json`의 공간 기준을 따른다. 실제 이미지 생성 전 각 숏의 위치를 간단한 평면도와 기준 이미지로 고정한다. 다른 위치·각도에는 새 자산이 필요하며 단순 크롭·확대는 새 시점으로 세지 않는다.

`editing-plan.json`은 기법 추천과 적용 위치를 정리한 계획이다. 실제 자산·모션·음향 구현과 렌더 검수를 뜻하지 않는다. 의도한 0.9초 적막은 실제 음성에 맞춰 다시 배치하고 직접 확인한다. 본편 연속 자막 미번인, 짧은 제목·단서 글자는 편집에서 입력한다.

본편과 쇼츠는 독립 음성·새 세로 이미지·별도 9:16 컴포지션이다. 쇼츠는 현재 약 19–20초 예상이며, 생성 후 15–40초·60fps·첫 프레임과 첫 음성·구문 자막·완전한 문장 끝을 각각 확인한다. 본편 정체·탈출법·결말은 쇼츠에 추가하지 않는다.

## 생성 음성 검수

본편·쇼츠 총 여섯 음성을 생성했다. 승인 원문 해시는 유지했다. C02 불량 테이크 교체, SH02 중복 제거, C01 ASR 재분석 보정과 숫자 표기 정규화를 각각 기록했다. 실제 발화에 맞춰 장면 경계를 정리했으며 내부 숏 전환과 효과 앵커는 장면 자산 검토 때 확정한다. 사용자 청취 확인 뒤 BGM 후보 단계로 넘어간다.
