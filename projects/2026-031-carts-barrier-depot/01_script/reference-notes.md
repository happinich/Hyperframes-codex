# 031 참고 소재와 각색 범위

조사일: 2026-10-18 KST. 사용자 요청: 기존에 지정한 유튜브 참고 채널의 이야기를 살펴보고 소재를 빌려 새 이야기를 쓴다.

이 회차는 원작 사연을 재현하는 허가된 각색물이 아니라 **공개 영상에서 확인한 일반 모티프를 바탕으로 새 사건과 결말을 만든 창작 공포(`fiction`)**다. 영상 속 실화 표시는 게시자의 주장으로만 기록한다. 원작 대사·자막·녹음·삽화·영상은 제작 자산으로 사용하지 않는다.

기존 [2026-10-12 보고서](../../../planning/horror-reference-monitoring/2026-10-12/report.ko.md)와 [아이디어 라이브러리](../../../planning/horror-reference-monitoring/ideas.json)를 먼저 읽었다. 라이브러리의 수선실·잔교·펜션은 029에서 이미 사용했으므로 새 소재로 채택하지 않았다. 이번 추가 확인은 해당 영상의 공개 스크립트 UI와 설명을 읽은 조사다. 직접 청취, 정상 속도 연속 시청, 원작 실화 검증은 수행하지 않았다. 자동 자막의 오인식은 원문 대사로 인용하지 않았다.

## C01 · 맨 뒤 카트의 젖은 손잡이

- 출처: 돌비공포라디오, [야근 금지 회사](https://www.youtube.com/watch?v=yL4tbBaVuH4&t=115s). 공개 페이지의 게시일은 2026-10-08.
- 직접 확인: 자막 01:55–03:23의 야근 제한 안내, 04:19–05:22의 밤 근무 공간과 낮은 위치에서 발견되는 위협. 첫 이야기 전체와 결말을 검토했다고 주장하지 않는다.
- 가져온 일반 모티프: 평범한 직장 인수인계에 설명되지 않은 회피 이유가 있다는 불안. 부분적으로 보이는 신체와 일상 업무의 결합.
- 새로 쓴 것: 마트 카트 회수자, 고장 카트의 주간 처리 절차, 마른 바닥·젖은 손잡이·운동화·체인, 보관장 안 직접 접촉과 쇠말뚝을 이용한 탈출, 사진 속 소매와 손목 감각의 잔상.
- 가져오지 않은 것: 회사·회계 업무, 원작 인물, USB 회수, 출현 시각이 앞당겨지는 구성, 원작 존재의 과거·후반 사건·결말.
- 사용 범위: 위의 모티프 수준. 설명란에서 콘텐츠 재가공 금지 문구를 확인했으므로 원작의 구체적 장면과 사건 연쇄를 재현하지 않는다.

## C02 · 방음벽 안에서 따라오는 것

- 출처: 왓섭! 공포라디오, [오대산에서 생긴 일](https://www.youtube.com/watch?v=bsI8CG-SuhQ&t=924s). 공개 페이지의 게시일은 2026-10-12.
- 직접 확인: 공개 자막의 이야기 구간 01:19–28:12와 해설 28:16–30:19. 특히 15:24–17:32 및 18:33–19:54에서 안전을 위한 연결이 위협이 되는 모티프를 확인했다. 직접 오디오를 청취한 기록은 아니다.
- 가져온 일반 모티프: 안전하다고 믿은 지지·연결 구조가 위험을 함께 전달한다는 역전.
- 새로 쓴 것: 현대 도로 방음벽 보수, 금속 점검로를 타고 전해지는 진동, 여섯 마디의 납작한 비인간 존재, 발판을 통한 물리 접촉, 다른 진동원으로 시선을 돌리는 선택, 새 패널 포장의 긁힘.
- 가져오지 않은 것: 실재 산·사찰, 캠핑·음주·급류, 친구 사칭, 줄로 사람을 묶는 행동, 과거 조난 집단과 생존자의 반전.
- 카메라 보조 근거: [Mr. Nightmare의 높은 시점과 낮은 철길 시점 표본](https://www.youtube.com/watch?v=Kyjxoqovpyw&t=35s)은 기존 보고서가 확인한 정지 화면 범위로만 쓴다. 도로 전체와 점검로 밑의 높이 차이가 새 정보를 주므로 적합하다. 컷 속도·전환 길이·음향 효과를 확인한 근거는 아니다.

## C03 · 예비 버스의 다음 정류장

- 출처: 괴들남 공포이야기, [제주도 택시 손님 사건](https://www.youtube.com/watch?v=G9cW9c8qu3g&t=422s). 공개 페이지의 게시일은 2026-10-12.
- 직접 확인: 자막 00:00–16:37. 07:02–10:59와 11:50–13:33에서 운송 종사자의 식별 정보와 일상 경로가 추적 불안으로 연결되는 상황을 확인했다.
- 가져온 일반 모티프: 일할 때 사용하는 식별·운행 정보가 오히려 자신을 찾아오는 수단이 된다는 불안.
- 새로 쓴 것: 가상의 버스 차고지, 시험용 위치 태그, 닫힌 예비 버스와 무인 이동, 현재 위치를 가리키는 행선지, 태그를 운반 카트에 옮기는 선택, 시험 설비 차단과 남은 승차 기록.
- 가져오지 않은 것: 원작 인물의 국적·지역·사연 주장, 분실 전화기 반환, 펜션·범죄 암시·동일 손님 재등장·주유소 탈출. 특정 집단을 위협의 근거로 사용하지 않는다.
