## 출처와 사용자 요청 반영

기존 레퍼런스 보고서의 정지 표본만으로 원작 이야기를 각색했다고 설명하지 않도록 수정했다. 돌비·왓섭·괴들남의 공개 스크립트 UI에서 `reference-notes.md`에 기록한 구간을 추가 확인했다. 직접 청취는 수행하지 않았다. 출처 링크·확인 구간·일반 모티프·새로 쓴 요소·미사용 요소를 편별로 남겼다. 세 편은 창작 공포이며 원작 실화 주장을 이어받지 않는다.

## 원고·동선 검토

- C01: 사진을 찍기 전후 수건 위치가 어긋났던 문장을 고쳤다. 고장 카트는 정상 11대와 포개지지 않은 별도 한 대로 설정했다. 정상 줄을 관통하지 않고 뒤에서 오른쪽 통로로 나와 직원을 막는다. 체인·바퀴·말뚝 접촉은 이미지 생성 전 별도 평면도와 접촉 기준으로 다시 확인할 항목이다. 손은 정상적인 다섯 손가락이며 엄지는 손잡이 아래로 감긴다.
- C02: 단순한 큰 소리와 구조물을 타는 진동을 구분했다. 떨어져 든 드라이버에는 반응하지 않고 금속 상자에 닿았을 때 반응한다. 점검로·왼쪽 계단·오른쪽 끝의 지리와 남겨진 왼쪽 작업화를 유지한다. 총 여섯 마디의 한 몸, 손가락 없는 회색 부속지가 의도한 존재 디자인이다.
- C03: 시험 위치 태그를 출입증에 임시 부착한 설정을 분명히 했다. 건물 차단기로 버스 배터리를 끈다는 잘못된 설명을 고쳐, 구역 수신기·시험 서버의 신호를 끊는 행동으로 정리했다. 봉인된 무전원 버스의 이동은 초자연적 현상이다. 태그와 화자를 떨어뜨린 실험을 거친 뒤 운반 카트에 태그를 옮긴다.
- 세 편 모두 일인칭 존댓말 구술형으로 작성했다. 귀신·괴물은 흔적→부분 공개→직접 상호작용으로 실재를 확인하고 기원은 남겼다. 세 편의 사건과 결말은 각각 닫는다.
- 쇼츠 세 편은 별도 원고이며 정체·탈출 선택·마지막 잔상을 공개하기 전에 완전한 문장으로 끝난다. 카트에는 소매 공개 전, 방음벽에는 존재 공개 전, 차고지에는 태그 추적·해결 공개 전을 사용한다.

## 구조와 파일 일치 검사

프로젝트 Python으로 아래 항목을 검사해 통과했다.

- 편별 원고를 이은 내용과 `narration.txt` 완전 일치.
- 각 편의 씬 원문을 이은 내용과 편별 원고 완전 일치.
- 모든 본편·쇼츠 장면의 `caption_text == narration_text`.

- 계획 모션 변화 간격 3초 이하. 실제 화면에서 의미 있는 변화인지 판정하는 검수는 제작 후 수행한다.
- 콜드 오픈 예상 길이 5–10초, 첫 이상 예상 약 58.2 / 55.6 / 47.8초.
- 본편 예상 1301.904초(21:41.9), 쇼츠 예상 약 20.5 / 19.2 / 20.1초. 이는 실제 생성 음성의 길이 검사가 아니다.
- 모든 JSON 파싱. 원고·스타일·프로젝트 보이스·BGM 승인 대기 상태를 분리했다.
