# 031 남성 보이스 비교 샘플

방음벽·차고지는 **동일한 남성 보이스 한 명**을 쓰는 구성이 승인됐습니다. 실제 남성 보이스 후보를 비교하기 위한 약 40초 샘플 두 개입니다. 두 샘플은 동일한 승인 대사 발췌, `eleven_v4`, Stability 0.5 / Similarity 0.75, 원본 1.00x로 생성했습니다. 미리듣기 사본은 음색에 영향을 주는 압축을 추가하지 않고 정적 볼륨만 조절해 출력 측정 기준 약 -23.4 LUFS로 맞췄습니다(후보 간 차이 0.01 LU). 원본 MP3를 보존했습니다.

| 후보 | 길이 | 제공자가 설명한 특성과 검토 방향 | 확인 결과 |
| --- | --- | --- | --- |
| **A · Hyuk — 우선 후보** | 40.32초 | 이야기 낭독용의 부드럽고 절제된 중년 한국어 남성으로 등록. 차분한 현장 복기와 후반 긴장 상승에 적합한 방향이라 우선 제안 | Whisper 원문 정렬 1.000. 두 이야기 발췌 경계에 0.88초 쉼 |
| **B · Harry Kim** | 39.84초 | 안정적이고 자연스러운 구술·대화형 한국어 남성으로 등록. 일상 경험담의 편안함을 비교할 대안 | Whisper 원문 정렬 1.000. 0.8초 초과 단어 간격 없음 |

두 샘플 모두 원문과 자동 받아쓰기의 문자를 공백·문장부호 정규화 후 대조해 일치했습니다. 덧붙은 반복 문구도 검출되지 않았습니다. 이 결과는 직접 청취를 대신하지 않습니다. 실제 음색, 첫 단어의 시작, 과장·속삭임·배경음 여부는 사용자 청취 확인을 기다립니다. 등록 설명에 따른 우선 제안이며 에이전트가 직접 들었다고 기록하지 않습니다.

본편 원고와 각 이야기의 쇼츠 원고는 그대로 유지합니다. 카트는 이미 승인된 Jian.K를 사용합니다. 화면 스타일은 카트 거친 2D / 방음벽 어두운 회화 / 차고지 픽셀아트 조합에 대한 별도 확인 대기입니다.
