# 원고·기획 검토 두 차례

작성일: 2026-10-08 KST. 검토 범위는 승인 전 본편·쇼츠 원고와 장면 계획이다. 음성 청취·개별 이미지·렌더 검수 기록이 아니다.

## 1차 — 구조·낭독·완결성

- 사용자 선택 세 편을 독립 합본으로 구성했다. 귀신·괴물·규칙 공포의 공간과 핵심 물건을 구별했다. 가상의 원고이며 실화로 표시하지 않는다.
- 인사 없이 각 편 훅→정상 공간→첫 이상→확인 행동→직접 위협→결정적 행동→잔상으로 연결했다.
- 울타리 첫 훅의 7어절이 기획상 5초에 미치지 않아 11어절로 보완했다. 저수조 훅의 “바닥 아래”는 관찰 가능한 위치와 맞도록 “물이 없는 바닥”으로 수정했다.
- 자연스러운 존댓말 구술을 유지했다. 태그·SSML·화면 안내 문장은 원문과 자막에 없다.
- 여성 보이스 요청을 기록하고 기존 한국어 여성 Esther를 선택했다. 보이스 계획은 API 실행이 아니며 원고 승인 전 생성하지 않는다. 본편 1.00배속, 길이·WPM 맞추기용 가속 금지.
- 쇼츠 1·3 초기 초안은 배속 후 15초 미만 위험이 있어 정상 상태·확인 행동을 보완했다. 세 쇼츠 모두 완전한 문장으로 끝나고 탈출 방법과 결말은 제외했다.

## 2차 — 공간·소품·접촉·공개 시점

- 저수조: 화자는 난간 위 점검실에 남는다. 작업대→사다리→철문→복도→계단을 유지했다. 봉투를 가슴에 끼우는 표현은 두 손으로 문을 당기는 동작과 충돌할 수 있어 재킷 안쪽 보관으로 수정했다. 손톱 사이의 머리카락은 손가락 사이로 구체화했다. 전화는 주머니, 손전등은 겨드랑이에서 떨어지고, 봉투는 계단에서 떨어진다. 회수된 물건의 출처를 대조했다. 문 안팎 두 팔·수평 몸·사다리 복구는 의도된 이상으로 별도 기준에 기록했다.
- 울타리: 텐트는 차 왼편, 차로는 오른편, 운전석은 차로 쪽. 전화 문자 뒤 재킷 주머니 보관을 추가해 차 키·탑승·시동 동작을 분리했다. 철망 아래 진입→지지대 접촉→왼쪽 뒤 문 압박→회전 탈출 순서를 대조했다. 팔다리 추가 마디를 고정할 기준을 기록했고 형태 오류와 구별하도록 했다.
- 문: 처음에는 나무문 하나, 현관·주방·방 구조는 고정이다. 상자·양말·벽지 변화 이후 반복 복도를 공개한다. 우산으로 상자 제거→우산 놓음→문 모서리 당김→회전해 눕힘의 소품 순서를 대조했다. 경첩 보이는 면과 후일 반대 방향은 의도된 단서다. 기원이 전부 설명되지는 않아도 세우기·받침 요청·눕히기·창고 재발의 관계가 완결된다.
- 쇼츠: 본편 탈출·사후 사진·창고 잔상은 넣지 않는다. 장면 원고와 자막을 동일하게 계획했다. 실제 길이는 생성 후 15~40초를 확인해야 한다.
- 각 편 사이 5초는 낭독 쉼이다. 완전 검정·전체 무음과 구분하고 5초 전환 비트와 청취 검수 필요를 기록했다.
- 스타일은 이번 이야기별 추천이며 아직 승인으로 기록하지 않는다. 저수조 회화·울타리 거친 2D·문 종이 무대와 대안을 제시했다. 참고는 2026-10-05 기존 화면 표본 분석이며 오디오·컷 속도 관찰이나 효과가 입증된 기술이라고 쓰지 않는다.

## 최종 재확인

수정된 6개 원고를 다시 읽고 동선·물건 행방·초반 공개·결말 제외를 대조했다. JSON·원고 일치·추정 타임라인·기법 ID·HTML 전체 원고 포함 여부는 별도 기획 파일 검사로 확인한다. 실제 이미지·TTS·컴포지션·영상·Drive 업로드는 아직 없다.

## 검토 화면 확인 제한

전체 원고가 HTML에 포함되고 문서 링크가 존재하는 것은 검사했다. 브라우저 도구의 URL 정책이 file:// 열기를 차단하여 실제 HTML 화면·버튼의 시각 검수는 수행하지 못했다. 우회하지 않고 전체 원고 Markdown을 Codex 파일 패널에 열도록 요청했다. 앱 응답은 queued이므로 실제 패널 표시를 확인한 것으로 기록하지 않는다. 이 제한은 원고 두 차례 읽기·동선 검토와 구분한다.
