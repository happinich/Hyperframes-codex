# 029 원고·장면 계획 검토

검토일: 2026-10-13 KST. 대상은 세 편의 전체 본편 원고, 세 편의 별도 쇼츠 원고, 초기 초 단위 씬 플랜이다. 모두 **승인 전 초안**이다. 아래 검토는 원고와 계획에 한정되며 음성 청취·생성 이미지·렌더 검수 통과를 뜻하지 않는다.

## 1차: 서사·분량·말투

- 기본 세 편 구성을 유지했다. 수선실은 물건 안쪽의 귀신 접촉, 잔교는 넓은 공간의 물리적 위협, 펜션은 문서와 공간의 규칙 위협이다. 두 편으로 줄이면 각각의 독립된 정상 상태·불일치·확인·선택·결말을 제거해야 하므로 이번 회차에는 맞지 않는다.
- 원고 단어 수는 수선실 1,046 / 잔교 1,033 / 펜션 959개다. 028편 실제 음성의 단어당 시간을 단순 대입한 **가설적** 계획 길이는 8분 57.8초 / 8분 51.1초 / 8분 13.1초다. 두 번의 5초 전환과 20초 엔드스크린을 더한 전체는 26분 32.1초다. 원본 1.00배속을 유지하고 실제 TTS·Whisper 후 재계산한다. 편당 목표 시간을 맞추려고 대사를 늘리거나 가속하지 않는다.
- 각 편의 첫 문장은 계획상 약 6.2 / 7.2 / 8.2초다. 인사·채널 범퍼가 없다. 첫 이상 징후는 원고 단어 위치를 기준으로 약 55 / 56 / 49초에 배치했다. 실제 음성에서 40–60초 창을 재확인한다.
- `~했어요`, `~였죠`, `~거든요`, `~더라고요` 등을 장면에 맞게 섞고, 설명형 화면 지시 문장을 쓰지 않았다. 세 편 모두 창작(`fiction`)으로 표기한다.
- 각 편은 독립 결말을 갖는다. 수선실은 천 손의 물리 접촉, 잔교는 회색 손의 직접 접촉으로 존재를 확증한다. 펜션은 출처 없는 키를 걸지 않는 한 규칙의 위반과 결과로 끝낸다.
- 쇼츠는 별도 대본이다. 수선실은 봉제선의 성장, 잔교는 압박 자국, 펜션은 도면의 새 칸까지만 보여 준다. 각 쇼츠는 완전한 문장으로 끝나며 본편의 탈출과 잔상 결말은 공개하지 않는다. 길이는 별도 TTS 뒤 확인한다.

## 2차: 공간·소품·연속성

- 수선실: 파란 가게 핀과 노란 미확인 핀을 구분했다. 작업대·재봉틀·서랍·뒷문 위치를 고정하고, 손목 접촉 뒤 실가위로 갈색 봉제선을 끊는 행동을 연결했다. 접수표 뒷면 글씨와 새 작업복의 한 땀은 서로 다른 시각 단서다. 노란 핀의 개수는 생성 이미지에서 다시 확인한다.
- 잔교: 육지 철문→긴 통로→배 끝 왼쪽 작업대의 축을 유지했다. 마른 회색 가루와 네모난 압박 자국은 물속 흔적과 구별했다. 손마다 네 손가락이며, 발판의 빠진 핀과 주인공이 넣는 예비 핀을 별도로 구분했다. 갈고리와 작업복 천이 직접 접촉의 물증으로 남는다.
- 펜션: 아홉 객실·아홉 정상 키를 고정했다. 미확인 키는 처음 하나에서 다른 흠집의 두 번째, 마지막 세 개로 늘어난다. 첫 도면의 흰 마당, 건물색으로 늘어난 네모, 끝의 흰 작업 구역을 서로 다른 단계로 구분했다. 컨테이너 문턱과 마당의 거리 이상은 사번 등록 이전에 발생한다.
- 전체: 원고와 각 씬의 `narration_text`/`caption_text`가 완전히 일치하고, 챕터별 씬 원문을 다시 이어 붙이면 각 편 원고와 동일하다. `narration.txt`도 세 편을 순서대로 이어 붙인 초안이다. 씬과 샷 ID 중복이 없다. 실제 음성 전의 시각·모션·효과음은 제안 상태이며, 편별 스타일 승인 후 구체화한다.
- 참고 조사 사용 범위: [2026-10-12 보고서](../../horror-reference-monitoring/2026-10-12/report.ko.md)의 일반 발상과 카메라 높이 관찰만 활용했다. 해당 공개 영상의 전체 이야기·대사·결말·오디오·컷 속도는 검증하지 않았다. 기존 012·015·022·027·028과 직업, 금기, 물건, 결말을 대조했다. 이 검토는 원고 수준의 독립성 점검이며 외부 영상 전체와의 동일성 검증을 뜻하지 않는다.

## 보이스 캐스팅 제안

- 우선 검토: 낮고 건조한 남성 목소리. 수선실의 실무적 설명에서 잔교의 육체적 긴장, 펜션의 기록 불안까지 감정을 과장하지 않고 이어 가기 좋다.
- 대안: 절제된 여성 목소리. 수선실의 가까운 일인칭 감정에는 강하나 028편의 여성 Esther와 인접한 인상이 날 수 있다.
- 세 화자의 성별은 이야기상 고정되지 않는다. 목소리 선택은 이번 회차의 별도 사용자 승인이 필요하다. 특정 보이스 ID나 생성 가능 여부는 아직 확인하지 않았다.

판정: 원고와 계획의 두 차례 검토를 마쳤고 사용자 원고 승인을 기다린다. 승인 뒤에도 비주얼 스타일·보이스·BGM은 각각 별도 결정한다.
