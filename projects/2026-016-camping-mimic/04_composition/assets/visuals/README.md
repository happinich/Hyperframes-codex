# Generated Visual Assets

All scene images in this directory were generated for this project with the built-in ImageGen workflow.

- `creature-reference.png`: canonical mimic design and color reference
- `camp-arrival.png`: deserted campground establishing image
- `tent-shadow.png`: first silhouette outside the tent
- `long-fingers.png`: physical clue under the tent floor
- `tent-tear.png`: direct interaction and partial reveal

The creature remains hairless and wet-black, with tree-bark texture, arms below the knees, reverse-bending joints, and a vertical facial slit. Human faces remain hidden.
