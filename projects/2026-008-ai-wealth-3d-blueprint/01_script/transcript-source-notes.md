# 전사 교정 메모

원본 음성은 유지하고, Whisper 자동 전사에서 명백한 오인식으로 보이는 단어만 대본 표기에서 교정했습니다. 최종 자막 싱크는 원본 음성 기준으로 다시 검증합니다.

- `분석 잔료` -> `분석 자료`
- `적이 현미경` -> `전자 현미경`
- `시냅시스` -> `시놉시스`
- `시넉시스` -> `시놉시스`
- `케이던스라는 기억` -> `케이던스라는 기업`
- `채찌 PT` -> `ChatGPT`
- `잿값` -> `제값`
- `고대역풍 메모리` -> `고대역폭 메모리`
- `대장관` -> `대장간`
- `타의 취종` -> `타의 추종`
- `하드웨어 사설` -> `하드웨어 사슬`
- `순간적으로 짜릿하게 남대 엄청 위험하죠` -> `순간적으로 짜릿하긴 한데 엄청 위험하죠`
- `불을 쌓으려면` -> `부를 쌓으려면`
- `단숭 명료` -> `단순 명료`
- `글로벌 1등 인프라 기업을 지고` -> `글로벌 1등 인프라 기업을 쥐고`
- `편익에 빠지시겠어요` -> `패닉에 빠지시겠어요`
- `훑어돈` -> `훑어본`
