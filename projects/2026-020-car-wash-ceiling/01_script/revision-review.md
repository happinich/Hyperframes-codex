# 추가 공포·개연성 검수

2026-09-20. 사용자가 대본 재검수와 필요한 공포 보강을 위임하고 다음 단계 진행을 요청했다. 이어 별도 질문에 추천 보이스·화면 스타일로 진행한다고 답했다.

## 약했던 부분과 수정

1. 관리인이 안전한 정답을 알려 주는 중후반: 빛을 비춰도 손이 버티고, 빛이 비끼면 즉시 다시 접근하도록 수정. 빛은 일시적인 틈일 뿐 퇴치가 아니다.
2. 차 안은 안전해 보이는 문제: 바깥에 손이 붙어 있는데 실내 유리에 입술 모양 김과 물기가 생긴다. 빈 조수석의 호흡이 주인공보다 먼저 움직인다. 귀신이 둘이라는 확정 설명은 하지 않는다.
3. 사무실의 반복적인 문 두드림: 머리카락이 몸을 따라가고 숨은 위치의 천장 위에서 멈추는 추적으로 바꾼다.
4. 마지막 물자국만 남는 결말: 정비사의 장갑이 끌려가고, 실내등 틈으로 손톱이 나와 귀신의 직접 재출현을 확인한다. 처음 경고를 마지막 화자의 대사로 회수한다.
5. 두 차량 방향 모순: 후진 진입한 관리인이 전진으로 안내한다. 오른쪽으로 비켜서 주인공이 왼쪽으로 먼저 나가도록 동선을 명시한다.

## 재확인

- 실제 눈맞춤은 일어나지 않는다. '눈 마주치면 떨어진다'는 관리인의 이전 경험에 근거한 경고다. 손이 닿는 것과 몸 전체가 떨어지는 것은 다르다.
- 직접 천장 전체를 쳐다보지 않고도 주변부의 손·발, 낮게 처진 형체는 볼 수 있다. 얼굴을 확인하는 컷을 생성하면 안 된다.
- 손전등은 초반 운전석 옆에 미리 놓는다. 조명은 기존 위협을 삭제하지 않고 구출 시간을 짧게 확보한다.
- 숫자 한글, 자연스러운 존댓말 구술, 23단락을 유지한다. 길이는 음성 실측 후 조정한다.
- 주인공·귀신 얼굴 반복, 고어, 갑작스러운 고음량에 의존하지 않는다.
- 48장 계획의 해당 장면을 함께 바꾼다. 원문·TTS·씬·예상 자막을 모두 재생성한다.

판정: 대본 보강 완료, 승인된 Bin 보이스 음성 생성으로 이동 가능. 이는 실제 음성/영상 검수 통과를 의미하지 않는다.
