상태: 제작 및 위임 검수 완료. 창작 공포 본편 약 10분 58초, 독립 쇼츠 약 23초. 실제 YouTube 업로드나 예약은 실행하지 않았다.

## 완성 파일

- 본편: `06_delivery/youtube/2026-020-car-wash-ceiling-youtube.mp4` (1920x1080, 60fps, 무번인)
- 쇼츠: `06_delivery/shorts/2026-020-car-wash-ceiling-shorts.mp4` (1080x1920, 60fps, 흰색/검정 테두리 문장 자막)

- 썸네일: `07_publish/youtube/thumbnail-a.jpg`, `thumbnail-b.jpg`

## 제작 및 검수

명시 승인된 Bin 남성 보이스와 차가운 형광등/붉은 후미등 호러 시네마틱을 사용했다. 이후 사용자에게 전체 검수·진행을 위임받아 BGM cand-02를 선택했다.

본편 생성 이미지 48장, 타임라인 49컷. 본편 검수 완료 뒤 쇼츠 전용 세로 이미지 6장과 음성을 새로 생성했다. 본편 이미지·프레임을 참조 입력, 추출, 크롭 또는 재사용하지 않았다.

실제 음성 타이밍으로 화면을 구성했다. 문자 정렬은 본편 99.12%, 쇼츠 100%. 소스 화면과 실제 인코딩 프레임을 각각 검수하고, 해상도/프레임레이트/영상·음성 길이/정지·검정 구간/복사 버튼·링크를 검사했다. 전체 인간 청취를 했다는 의미는 아니다. 범위와 잔여 한계는 `05_review/final-review.md`에 기록했다.

영상·음성·렌더 중간파일은 Git 제외 대상이며 이 컴퓨터에 저장한다. 생성 이미지, 원고, 타이밍, 컴포지션, 제작 스크립트, 검수 기록, 게시 자료를 Git에 보관한다.
