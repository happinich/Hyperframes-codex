# 세차장 천장의 여자

현재 단계: 보강 대본과 Bin 음성 생성 완료, 자동 정렬·무음 검사 완료, 청취 검토 대기. 완성 영상은 아직 없습니다. `05_review/voice-review.html`에서 약 10분 54초 음성을 확인합니다.

- `01_script/narration.txt`: 사용자 위임 검수를 거친 원문
- `01_script/대본-전체검토.md`: 본편과 별도 쇼츠 검토 문서
- `01_script/revision-review.md`: 공포 강화 및 차량 동선 수정 기록
- `01_script/scene-plan.json`: 녹음 전 예상 타이밍. 실제 음성 타이밍으로 교체해야 함
- `02_audio/inbox/`: 원본 음성, Git 제외
- `02_audio/working/`: 검수·보정 음성, Git 제외
- `03_sync/`: 자막·정렬·속도 검수 자료
- `05_review/`: 현재 단계 결과 기록

승인: 사용자가 대본 추가 검수를 위임하고 다음 단계 진행을 요청했으며, 별도 질문으로 Bin 보이스와 차가운 형광등/붉은 후미등의 호러 시네마틱을 승인했습니다. BGM 및 독립 쇼츠 대본은 아직 승인 대기입니다.

자동 생성된 composition/delivery/publish 템플릿은 완성 산출물이 아닙니다. 영상 제작과 검수가 완료되기 전에는 게시하지 않습니다.
