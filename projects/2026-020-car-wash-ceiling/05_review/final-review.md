# 최종 위임 검수

## 결과

본편 및 독립 쇼츠 제작 완료. 사용자 지시로 검수를 수행하고 추가 승인 요청 없이 다음 단계로 진행했다. 아래 두 검수 단계를 모두 통과했다.

### 1차: 원고·소스 컴포지션

- 본편: 승인 원문 1,378어절과 자막 텍스트 일치. 자동 ASR 문자 정렬 99.12%.
- 본편 48개 생성 이미지, 49컷. 단어 타이밍에 맞춰 약 0.25초 선행 노출. 전체 시간축에 컷 공백 없음.
- 조기에 나타난 인물, 차량 방향 불일치, 마지막 낮 장면의 얼굴 노출을 재생성으로 수정했다.
- 소스 화면의 모든 본편 컷, 쇼츠 6컷, 텍스트 경계, 이미지 디코딩을 검사했다.
- 본편 Hyperframes lint: 오류 0, 경고 0. 쇼츠는 strict 렌더 컴파일 및 별도 레이아웃 검사를 통과.
- 첫 물자국은 약 36초. 기본 40~60초보다 빠르지만 승인된 음성을 늘리지 않는 예외로 남겼다.

### 2차: 인코딩 파일

- 본편 영상 657.900초, 오디오 657.895초. 차이 0.005초.
- 본편 1920x1080 / 60fps / H.264 / AAC. 평균 -18.5dB, 피크 -3.0dB.
- 쇼츠 1080x1920 / 60fps / H.264 / AAC. 약 23.45초.
- 양쪽 모두 3초 초과 정지 및 1초 이상 검정 구간 검출 없음.
- 인코딩된 초반/중반/후반/전환/엔딩 프레임을 확인했다. 쇼츠의 여섯 이미지와 문장 자막은 별도 소스 프레임에서도 확인.
- 본편 무번인 + SRT/VTT, 쇼츠 문장 번인 + SRT/VTT. 움직이는 단어 강조 없음.
- 쇼츠 첫 120ms의 목소리 샘플은 0.0으로, 이전 영상 잘린 음성의 재사용이 없다.
- 쇼츠 끝 1초 RMS 약 -42.7dB, 끝 100ms 약 -63.5dB로 BGM 페이드 확인.
- 마지막 말은 19.42초에 완결. 원음 19.448초 뒤 BGM 여운 4초를 둔다.

## 새로 만든 쇼츠

본편 검수 완료 후 이미지 6장을 내장 ImageGen으로 각각 신규 생성했다. 본편 이미지를 입력 참조하거나 추출하지 않았다. 신규 파일은 `short-new-01.png`~`short-new-06.png`이다. 생성 경로·프롬프트·빈 참조 목록은 `04_composition/image-sources.json`에 저장했다.

`shorts-originality-check.json`은 여섯 세로 이미지, 독립 생성 이력, 본편과 다른 SHA-256, 쇼츠 타임라인의 전용 이미지 경로를 검증한다. 단순 해시 비교만으로 재사용 여부를 주장하지 않고 실제 생성 이력 및 시각 구도를 함께 확인했다.

별도 원고로 Bin 음성을 새로 생성하고 피치 보존 1.07배 후처리했다. 문자 정렬 100%, 긴 무음/단어 공백 0. 마지막 15~19.42초의 느린 창 표시는 8어절을 15초 분모로 나눈 결과이며, 실제 구간 기준 약 109어절/분이다.

## 게시 패키지

썸네일 2개, 메인 제목과 추천 제목 5개, 설명/타임스탬프/태그, 고정 댓글, SNS 홍보문, 실험 게시 시간을 준비했다. 본편 및 쇼츠 HTML의 전체/개별 복사, 로컬 파일 fallback, 링크 존재, 모바일 가로 넘침 검사를 통과했다.

게시 시각은 채널 분석 자료로 확정한 최적 시간이 아닌 초기 실험 제안이다. 실제 YouTube 업로드·예약·관련 동영상 지정은 실행하지 않았다.

## 검수 범위 및 한계

전체 음성을 사람이 직접 듣고 검수했다고 주장하지 않는다. 자동 ASR, 신호/무음/피크 검사, 구간별 재인식 및 시각 프레임 검토에 근거한다. 높은 정렬률도 억양·감정 표현의 완벽함을 보장하지 않는다. 생성 이미지의 연속성은 공간·차량·의복·단서를 기준으로 검토했으나 실사 촬영의 완벽한 동일성을 뜻하지 않는다.

오디오/영상 원본과 렌더 파일은 로컬 보관, Git 제외. 원고·이미지·컴포지션·타이밍·검수·게시 자료를 저장한다.
