# 위임 검수 및 진행 기록

사용자 지시: 검토를 모두 맡기고 다음 단계로 진행. 본편 완료 후 쇼츠는 본편에서 추출하지 않고 새로 제작.

- 본편 원문은 변경하지 않는다. 기존 음성의 신호 검사와 전체 ASR 정렬을 재확인했다.
- 6개 구간을 독립 ASR로 다시 확인했다. 원문 흐름을 확인했으며, 잘린 구간 끝의 인식 오류(예: 감사합니다) 및 동음 단어는 완전한 문장 맥락과 전체 정렬 결과로 구분한다. 독립 ASR도 청각적 확증을 대신하지 못한다.
- 전체 99.12% 문자 정렬, 긴 무음 0, 긴 단어 공백 0. 마지막 짧은 창의 낮은 WPM은 분모 문제로 설명된다. 빠른 창은 최대 160어절/분이며 음성을 재생성하지 않고 현 보정본을 유지한다.
- 이번 진행 판단은 자동 ASR/파형/구간 분석에 근거한다. 인간처럼 전체를 직접 청취했다고 기록하지 않는다.
- BGM 2개를 새로 생성. cand-01 평균 -18.5/피크 -0.5 dB, cand-02 평균 -15.6/피크 -3.1 dB. 순간 피크 대비 평균 차이가 작은 cand-02를 선택하고 원본 대비 -18 dB로 낮춘다.
- 사용자의 위임에 따라 음성/BGM 검토를 진행하고 시각 제작으로 이동한다. 설정에 기록된 보이스와 스타일의 명시 승인은 유지한다.
- 쇼츠 원고 검수·제작도 위임 범위에 포함한다. 이미지 6장은 독립 image_gen 호출로 생성하고 본편 이미지·프레임을 입력 참조나 크롭 원본으로 사용하지 않는다. 새 TTS와 9:16 컴포지션으로 만든다.
- 본편 먼저 렌더·검수한 다음 쇼츠 생성·렌더. 자동 공개나 예약은 실행하지 않는다.
