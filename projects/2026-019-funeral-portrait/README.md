음성과 영상은 .gitignore에 따라 로컬에 보관합니다. Git에는 대본, 제작 소스, 생성 이미지, 자막, 검수 기록과 게시 자료만 올립니다. API 키는 포함하지 않습니다. `prepare.mjs`는 초기화 전용이며 완료된 프로젝트에서 다시 실행하면 확정 타이밍을 덮어쓰므로 실행하지 않습니다.

사용자의 이번 편 위임 승인에 따라 별도 질문 없이 진행했습니다. 실제 유튜브 업로드·예약은 실행하지 않습니다.
