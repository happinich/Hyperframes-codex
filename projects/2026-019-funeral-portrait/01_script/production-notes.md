# 제작 기록

## 승인 및 대본

사용자가 대본 검수와 완성까지의 진행을 위임했다. 추천 Bin 남성 보이스와 horror_cinematic_story_v1 / horror_cinematic을 채택했다. 기존 대본의 의자 복선과 카트 잠금 표현만 보정했고, 본편의 전개와 결말은 유지했다. 창작 공포이며 실제 시설이나 인물을 묘사하지 않는다.

## 음성

ElevenLabs eleven_v3, 계정의 Bin 보이스 jB1Cifc2UQbq1gR3wnb0. 기존 API 청크 생성 로직으로 다섯 부분을 순서대로 생성했다. 원본 MP3는 보존한다.

원본 약 869.954초에서 불필요한 긴 무음 163.513초를 정리했다. 무음 정리 후 706.441초 음성을 음색 보존 atempo=1.09로 보정해 648.120초로 만들었다. 완성 오디오는 BGM 여운 4초를 포함한 약 652.120초다. 승인 원문의 문장을 삭제하거나 순서를 바꾸지 않았다.

Whisper large-v3-turbo 전체 대조 98.95%, 평균 약 126어절/분. 0.8초 초과 무음과 단어 간격은 0개. 마지막 3초만 남은 구간이 15초 분모로 계산돼 느린 구간으로 분류된 것은 실제 지연이 아니다. 빠른 구간과 끝부분을 별도 ASR로 재대조했다. '닦고/닫고' 같은 받아쓰기 표기 차이가 있으므로 ASR이 발음의 완전성을 보장한다고 기록하지 않는다. 사람이 전편을 청취한 검수로 표기하지 않는다.

기획표에 제안한 0.9초 적막은 최종 음성에 별도로 삽입하지 않았다. 최종 타이밍은 모두 실제 음성의 단어 시작에 맞췄다.

## 음악 및 화면

신규 60초 BGM 두 곡 중 cand-01을 자율 선택했다. 후보 1의 평균/최대 음량은 -22.3/-9.9dB, 후보 2는 -16.9/-5.6dB였다. 더 조용한 후보에 -18dB 게인을 적용해 내레이션을 우선했다. 여운에서는 -14dB, 마지막 3초 페이드. 선택 이유는 측정 음량과 요청한 억제된 분위기이며, 실청을 수행했다고 주장하지 않는다.

48장 본편 이미지, 별도 세로 이미지 2장, 썸네일 2장을 built-in ImageGen으로 제작한다. 최초 이미지 검사에서 빈 공간에 불필요한 귀신이 등장하거나 사진과 현실의 경계가 잘못 표현된 컷을 발견해 교체한다. 최종 승인된 자산만 assets/visuals 아래에서 사용한다. 이미지 프롬프트와 수정 이력은 04_composition에 보관한다.

제한된 여유 디스크 때문에 장면별로 나누어 60fps로 렌더하고, 영상 스트림을 연결한 뒤 완성 오디오 한 트랙을 한 번만 합친다. 반복 청크별 오디오 인코딩으로 경계가 생기지 않게 한다.

## 쇼츠

본편 음성을 자르지 않고 별도 무스포 대본으로 새로 녹음했다. 피치 보존 1.07배 후처리와 긴 쉼 정리, 독립 Whisper 정렬을 수행했다. 갑작스러운 첫 소리의 진입을 완화하도록 첫 6ms 페이드와 120ms 선행 무음을 넣고 자막을 다시 정렬했다. 별도 세로 이미지, 상단 훅, 모바일 안전 구문 자막을 사용한다. 자리 교환과 작업복 결말은 드러내지 않는다.

## 검수 기록 구분

대본 2회 검토, 자동 ASR·신호 검수, 이미지와 실제 렌더 프레임의 시각 검수는 서로 다른 검사다. 아직 실행되지 않은 영상 검수는 이 문서만으로 통과 처리하지 않는다. 최종 결과는 05_review의 개별 보고서를 확인한다. 유튜브 업로드나 예약은 실행하지 않는다.
