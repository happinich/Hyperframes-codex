# 독립 쇼츠 원고 검수

사용자 별도 제작 승인: “쇼츠도 만들어줘”. 앞서 제시한 여섯 문단 원고 그대로 사용한다.

첫 문장에서 장화의 수면 이동을 제시한다. 사라진 장화 → 젖은 손바닥 흔적 → 고무 밑창 소리 → 다가오는 두 짝 → 난간에 올라온 한 짝으로 압축한다. 마지막 문장은 완결된다. 장화 안의 팔과 귀신의 정체, 구조 방법, 사진 결말은 공개하지 않는다. 숫자 없음, 설명형 메타 멘트 없음.

신규 세로 이미지 여섯 장, 별도 Bin V3 음성, 피치 보존 1.07배, 120ms 시작 여백, 15~40초 최종 길이, 의미 단위 흰색/검정 테두리 자막. 본편은 변경하지 않는다.
