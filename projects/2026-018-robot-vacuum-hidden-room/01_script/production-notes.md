# 제작 기록

## 원문과 승인

기획 폴더의 승인 대본을 그대로 사용했다. 한글 숫자, 흰 외벽과 꽃무늬 안쪽 벽지, 카메라 금기의 회수, 한 손으로 청소기를 잡고 다른 손으로 휴대전화를 쓰는 동작, 이사 뒤의 여운을 유지한다. 이 작품은 창작이며 실화로 표시하지 않는다. 사용자는 추천 방향과 중간 승인 없이 완료까지 진행하도록 승인했다.

## 음성

Eleven V3로 문장 경계 3개 청크를 순차 생성했다. 과거 Bin ID는 API 404가 나서 현재 계정의 Bin - Measured and Serious를 사용했다. 기존 아이디와 같은 음색이라고 단정하지 않고 현재 선택 이름과 아이디를 기록한다.

처음 생성된 약 560.72초 음성에는 문장 사이 긴 무음이 반복되어, 원본을 보관하고 무음 중간만 총 89.620초 줄였다. 발화 속도·피치·대본은 변경하지 않았다. 최종 목소리는 471.100초, BGM 여운을 포함하면 475.100초다.

보정 후 Whisper turbo 재정렬에서 긴 무음 및 0.8초 이상의 단어 사이 간격은 모두 0개다. 평균은 119.9어절/분이다. 끝의 짧은 잔여 분석창 두 개는 15초 창을 채우지 못해 발생한 경고다. 일부 숫자 인식 표기 차이는 원문을 바꾸지 않고 한글 자막을 유지한다.

쇼츠는 본편 발췌가 아니라 별도 원문으로 새로 녹음했다. 피치 보존 1.07배 후 긴 문장 간격만 0.4초로 줄였다. 목소리 약 16.82초, 여운 포함 약 20.82초다.

## BGM과 효과음

신규 생성 후보 두 개 중 cand-01을 선택했다. 후보 1의 평균 -17.2dB, 최대 -5.2dB로 후보 2(-14.9/-1.7dB)보다 절제된 신호이며, 요청한 실내 험·기계음 분위기에 맞는 생성 방향이다. 내레이션 아래 -18dB, 종료 후 -14dB, 마지막 3초 페이드다.

별도 룸톤과 알림·모터·긁힘·발소리 트랙은 프로젝트 전용 절차 생성 소스로 제작했다. 내레이션은 그대로 보존하며 갑작스러운 큰 효과음을 피했다. 오디오 검수는 파형·음량·무음·Whisper 재인식 기반이다. 사람이 전편 청취한 것으로 기록하지 않는다.

## 화면

17개 대본 씬을 실제 발화 경계에 맞춘 67개 화면으로 구성한다. `scene-plan.json`은 최종 발화 타이밍, `04_composition/scene-data.json`은 화면 전환의 기준이다. 단서를 약 0.22~0.35초 먼저 준비하되 후반의 귀신과 결말을 초반에 보여 주지 않는다. 첫 콜드 오픈에는 벽에 들어간 청소기만 보여 준다.

화면에 없는 방은 직접 그린 가상 지도, 과거 도면과 현재 도면은 단계별 표시, 마지막 사람 모양 점은 벽을 지나 침대로 움직인다. 평면도는 사건 설명을 위한 창작 그림이다. 주요 이미지는 이 프로젝트에서 새로 생성했으며 코드 기반 지도와 소품 모션을 결합한다.

## 재현 순서

이미 생성된 음성을 다시 과금 생성하지 않는다. 필요한 경우 아래 프로젝트 전용 제작기를 사용한다.

1. `build-composition.mjs`: 최종 음성·단어 타이밍에서 화면과 쇼츠 구성 재생성.
2. `sound-design.py`: 기존 음성/BGM에서 룸톤과 효과음·최종 믹스 생성.
3. `review-composition.mjs`: 화면 배치와 시간, 이미지 로딩 검사 및 검수 프레임.
4. `render-segmented.py`: 본편을 씬별 60fps로 렌더하고 원본 최종 음성과 무손실 영상 병합. 저장 공간 부족에 대응하는 프로젝트 전용 경로다.
5. 저장소의 `scripts/render_project.py --format shorts`: 별도 쇼츠 렌더.
6. `build-publish.mjs`: HTML 도우미, 단일 Markdown, 게시 메타데이터 생성.

본편 일괄 렌더는 임시 프레임 약 6GB에서 중지하고 해당 임시 작업만 정리했다. 구간별 렌더는 같은 Hyperframes 화면을 사용하며, 별도 인코딩된 음성을 잇지 않고 전체 오디오를 마지막에 한 번 합쳐 접합부 음성 끊김을 방지한다.

`produce.mjs init`와 `shorts_audio.py`는 초기 준비용이므로 완료 음성을 유지하려면 반복 실행하지 않는다. API 키는 `.env`/환경 변수에만 있으며 이 프로젝트 파일에는 포함하지 않는다.
