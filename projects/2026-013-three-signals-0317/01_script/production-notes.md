# 연출 노트: 새벽 3시 17분, 절대 응답하면 안 되는 세 가지 신호

`narration.txt`에는 읽을 문장만 넣고, 이 파일에는 발음·호흡·연출 지시를 적습니다.

## ElevenLabs 지시

- Voice: Bin (`jB1Cifc2UQbq1gR3wnb0`), 사용자 승인 완료
- API model: `eleven_v3`
- Language code: `ko`
- Output format: `mp3_44100_128`
- Pace: 느리지만 늘어지지 않는 공포 낭독. 문장 사이 긴 무음과 단어 반복은 허용하지 않는다.
- Emotion: 낮고 절제된 긴장감. 반전과 마지막 문장은 강도를 높인다.
- Pronunciation notes: 모든 숫자·호수·동·시각은 `tts-narration.txt`의 한글 발음 표기를 사용한다.
- Required user inputs: `ELEVENLABS_API_KEY`는 로컬 환경 변수에서만 읽는다.

## 원고 변환 프롬프트 규칙

하이퍼프레임스 롱폼 성공 팁:

1. 초반 3초 후킹: 영상 시작 부분의 지루한 인사말이나 일반론은 삭제한다. 첫 문장은 시청자의 호기심을 자극하는 날카로운 질문형 문장, 핵심 수치, 또는 반전 사실로 시작한다.
2. 시각 자료 힌트 주입: 하이퍼프레임스에서 자막, 이미지, 그래프를 타이밍에 맞춰 띄우기 좋도록 문맥 중간에 "지금 화면에 나오는 이 부분을 보시면...", "이 수치가 의미하는 것은..." 같은 시각적 안내 멘트를 자연스럽게 삽입한다.
3. 구어체 텐션 극대화: 일레븐랩스 V3의 억양이 살아나도록 문장 끝을 완전한 대화체로 바꾼다. 예: "~아시죠?", "~거든요". 호흡이 늘어지지 않도록 문장은 짧고 타이트하게 쪼갠다.

## 편집 메모

- 음악 방향: 보이스 검수 통과 후 별도 후보를 만들고 사용자 승인을 받는다. 승인 전에는 자동 합성하지 않는다.
- 핵심 이미지/도표: 폐쇄 병동 호출등, 현관 CCTV 타임라인, 심야 택시 미터기와 내비게이션. 세 이야기 모두 붉은 `03:17` 신호로 연결한다.
- 출처 확인이 필요한 자산:
- 제작 프로필: `classic_rich_motion_v1` · 기존 리치 모션형
- 프로필 설명: 밝은 카드, 다층 패널, 지도, 표, 허브 도식과 장면별 색조 변화를 사용하는 기존 Hyperframes 제작 방식.
- 레이아웃 문법: 대형 패널, 2열 카드, 차트, 지도, 허브, 전체 화면 타이포를 장면마다 교차 사용한다.
- 프로필 모션 밀도: 의미 있는 정보 변화가 최소 3초마다 발생하고 배경 미세 움직임을 유지한다.
- 목표 낭독 속도: 95–135 WPM
- 자막 적용 렌더러: `scripts/burn_story_captions.mjs`
- 자막 스타일: 하단 중앙 44px 흰색 구문 자막, 6px 검정 외곽선, 단어별 색상 추적과 이동 효과 없음.
- 승인된 화면 스타일: `dark_cinematic` · 다크 시네마틱
- 화면 분위기: 긴장감 있고 몰입도 높은 영화형
- 배경: 블랙, 딥 네이비, 짙은 그라데이션과 국소 조명
- 팔레트: #05070d, #0b1730, #172b4d, #f5f7ff, #ff4d5f
- 스타일별 모션: 빛 스윕, 깊은 줌, 강한 대비 전환, 느린 입자 이동
- 모션 기준: 의미 있는 정보 변화가 최소 3초마다 발생하고 배경 미세 움직임을 유지한다.
- 챕터 팔레트: 병원은 청록 형광등과 붉은 호출등, CCTV는 냉청색과 디지털 노이즈, 택시는 젖은 황색 가로등과 붉은 후미등.
