# Generated Visual Assets

All scene images were generated for this project.

- `hallway-trail.png`: goshiwon corridor with a wet drag mark
- `shower-room.png`: three-stall shared shower, middle stall papered shut
- `gray-slippers.png`: dripping gray rubber slippers
- `boiler-switch.png`: wall boiler remote with one red LED
- `steamed-mirror.png`: inside-pressed handprint on fogged glass
- `two-feet.png`: living feet beside pale wrinkled feet
- `hair-gap.png` / `hair-over-stall.png`: wet black hair without a face
- `wrist-grab.png`: pale hand through the stall gap
- `empty-stall.png`, `slippers-at-door.png`, `drain-hair.png`, `slipper-under-door.png`: escape and residual beats
- `shorts-*.png`: vertical stills for the 9:16 teaser

Human faces stay hidden. The ghost is shown as wet hair, swollen feet, and a wrinkled wrist.
