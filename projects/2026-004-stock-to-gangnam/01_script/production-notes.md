# 연출 노트: 주식에서 부동산으로, 왜 강남인가

`narration.txt`에는 읽을 문장만 넣고, 이 파일에는 발음·호흡·연출 지시를 적습니다.

## ElevenLabs 지시

- Voice: 흥미로운 투자 브리핑 톤. 숫자는 또렷하게, 질문 문장은 살짝 낮고 강하게.
- API model: `eleven_v3`
- Language code: `ko`
- Output format: `mp3_44100_128`
- Pace: 1.0x 기준. 숫자 구간은 천천히, 결론 구간은 확신 있게.
- Emotion: 위기감보다 "돈의 흐름을 먼저 읽는 사람"의 차분한 긴장감.
- Pronunciation notes:
  - `GBC`: 지 비 씨
  - `GTX-A`: 지 티 엑스 에이
  - `GTX-C`: 지 티 엑스 씨
  - `위례신사선`: 위례 신사선
  - `영동대로`: 영동대로
  - `압구정`: 압구정
  - `대치`: 대치
  - `개포`: 개포
- Required user inputs: `ELEVENLABS_API_KEY`, `voice_id`.

## 원고 변환 프롬프트 규칙

하이퍼프레임스 롱폼 성공 팁:

1. 초반 3초 후킹: 인사말 없이 "주식으로 번 돈, 결국 어디로 갈까요?"로 시작한다.
2. 시각 자료 힌트 주입: 숫자와 지도 구간에서 "지금 화면에 나오는 이 숫자", "지금 화면에 보이는 이 구조" 같은 멘트를 살린다.
3. 구어체 텐션 극대화: "~거든요", "~아닙니다", "~봐야 합니다"를 살려 V3 억양을 활용한다.

## 편집 메모

- 음악 방향: `library/audio/music/midnight-library.mp3`를 낮게 깔고, 엔딩에서 4초 여운 후 3초 페이드아웃.
- 핵심 이미지/도표:
  - 3.7조 자금 이동 카드
  - 서울 지도와 강남구/송파구/서초구 자금 유입 막대
  - 삼성역 영동대로 지하 5층 환승센터 단면
  - GBC 49층 3개동 추상 실루엣
  - 압구정 2~5구역 한강변 블록
  - 삼성·압구정·대치·개포 4축 결론 맵
- 출처 확인이 필요한 자산: 기사 화면 직접 캡처는 피하고 자체 제작 데이터 카드 사용.
- 화면 톤: 밝은 투자 브리핑. 흰색/라이트 블루/민트 배경, 골드 자금 흐름, 진한 네이비 텍스트.
- 모션 기준: 최소 3초마다 시각 변화. 긴 정지 화면 금지.
- 주의: 수익 보장 표현 금지. "자료상 강한 후보", "방향성", "자금 흐름"으로 표현.
