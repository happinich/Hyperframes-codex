# 연출 노트: Google I/O 2026, 무엇이 달라졌나

`narration.txt`에는 읽을 문장만 넣고, 이 파일에는 발음·호흡·연출 지시를 적습니다.

## ElevenLabs 지시

- Voice: 신뢰감 있는 한국어 뉴스/다큐 톤, 성별 무관.
- API model: `eleven_multilingual_v2`
- Language code: `ko`
- Output format: `mp3_44100_128`
- Required user inputs: `ELEVENLABS_API_KEY`, `voice_id`, 필요 시 `voice_settings`.
- Pace: 1.02x 수준의 자연스러운 빠르기. 문단 사이 0.25~0.4초 호흡.
- Emotion: 발견의 흥미는 유지하되 광고처럼 과장하지 않음.
- Pronunciation notes: `Google I/O`는 "구글 아이오", `Gemini`는 "제미나이", `Omni`는 "옴니", `SynthID`는 "신스아이디", `Antigravity`는 "안티그래비티", `Android XR`은 "안드로이드 엑스알", `Google Pics`는 "구글 픽스"로 읽기.

## 편집 메모

- 음악 방향: 110 BPM 안팎의 미니멀 테크 펄스. 시작과 결론에서만 상승, 내레이션 중 음량은 낮춤.
- 핵심 이미지/도표: 네 개 축 지도(모델/검색/일상과 업무/개발과 기기), 출시 상태 배지, 추상 UI 카드, 안경 실루엣.
- 출처 확인이 필요한 자산: Google 및 제품 로고 사용 여부, 공식 UI 캡처 사용 시 라이선스/출처. 최초 버전은 텍스트와 자체 제작 도형 중심으로 제작.
- 화면 정책: 얼굴이 보이는 키노트 영상이나 스마트 안경 착용 모델 사진은 사용하지 않음.
- 화면 톤 업데이트: 이후 렌더는 어두운 네이비 배경 대신 화이트/라이트 블루/민트 기반의 밝은 테크 브리핑 톤을 사용한다.
- 모션 기준: 최소 3초마다 카드 이동, 숫자 카운트업, 하이라이트, 줌, 배경 패턴 이동 중 하나를 넣어 정지 화면을 피한다.
