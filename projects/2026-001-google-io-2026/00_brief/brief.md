# Google I/O 2026, 무엇이 달라졌나

- Project ID: `2026-001-google-io-2026`
- Created: `2026-05-25`
- Primary format: YouTube 16:9 (1920x1080, 30fps)
- Secondary format: Shorts 9:16 (1080x1920, separately adapted)
- Face policy: 얼굴 노출 없음. 그래픽, 타이포그래피, 아이콘, 화면 목업만 사용.

## 목표

Google I/O 2026에서 발표된 주요 새 기능을 일반 시청자에게 약 3분 안에 설명한다. 기능 나열보다 Google 제품이 "답을 주는 AI"에서 "대신 실행하는 AI"로 이동한다는 공통 흐름을 전달한다.

## 시청자

새로운 AI 기능, Google 서비스, 개발 도구 변화가 궁금하지만 전체 키노트를 볼 시간은 없는 한국어 YouTube 시청자.

## 한 문장 메시지

Google I/O 2026의 핵심은 Gemini가 검색, 업무, 제작, 개발, 기기로 확장되며 실제 행동을 맡기 시작했다는 것이다.

## 톤과 시각 방향

- Tone: 빠르지만 과장하지 않는 테크 뉴스 브리핑.
- Recorded runtime: 3분 38초 (전달된 ElevenLabs 음성 기준).
- Visual style: 밝은 테크 브리핑. 화이트/라이트 블루/민트 기반, Google 컬러 포인트, UI 카드와 키네틱 타이포그래피.
- Brightness update: 이후 HyperFrames 렌더는 전체적으로 밝은 배경과 선명한 다크 텍스트를 기본값으로 사용한다.
- Timing policy: 기획 단계부터 초 단위 씬 타임라인을 작성하고, ElevenLabs API 생성 후 Whisper `large-v3` 단어 타이밍으로 실제 싱크만 보정한다.
- No face: 발표자 영상, 인물 사진, 아바타 얼굴 사용 없음.
- Availability rule: "오늘 사용 가능", "롤아웃 중", "올여름", "올가을", "예정"을 화면 배지로 구별.
