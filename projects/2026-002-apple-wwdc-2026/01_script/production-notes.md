# 연출 노트: WWDC 2026, 애플이 다시 기대받는 이유

`narration.txt`에는 읽을 문장만 넣고, 이 파일에는 발음·호흡·연출 지시를 적습니다.

## ElevenLabs 지시

- Voice: 궁금증을 끌어내는 한국어 테크 뉴스 톤. 첫 문장은 낮고 또렷하게, 질문 문장은 살짝 힘을 준다.
- API model: `eleven_v3`
- Language code: `ko`
- Output format: `mp3_44100_128`
- Pace: 1.02x. 첫 훅은 또렷하게, 중반 정보 구간은 빠르게, 결론 질문 전 0.4초 호흡.
- Emotion: 기대감과 긴장감을 함께 유지하되 루머를 확정처럼 말하지 않는 절제된 톤.
- Pronunciation notes: `WWDC`는 "더블유더블유디씨", `Apple Intelligence`는 "애플 인텔리전스", `Siri`는 "시리", `iOS`는 "아이오에스", `iPadOS`는 "아이패드오에스", `macOS`는 "맥오에스", `Shortcuts`는 "단축어"로 읽기.
- Required user inputs: `ELEVENLABS_API_KEY`, `voice_id`, 필요 시 `voice_settings`.

## 편집 메모

- 음악 방향: 104 BPM 안팎의 밝고 미니멀한 테크 펄스. 훅과 결론에는 짧은 정지감을 넣어 질문을 살린다.
- 핵심 이미지/도표: `Can Apple prove AI?` 질문 카드, 공식/미확정 분리 카드, Siri 시험지, 기본 앱 침투 그래픽, Proof vs Delay 갈림길.
- 출처 확인이 필요한 자산: Apple 로고와 공식 UI는 직접 복제하지 않음. 자체 제작 추상 카드와 아이콘 사용.
- 화면 톤: 밝은 테크 브리핑. 흰색/라이트 블루/민트 배경, 진한 텍스트, 부드러운 그림자.
- 모션 기준: 최소 3초마다 시각 변화. 긴 정지 화면 금지.
