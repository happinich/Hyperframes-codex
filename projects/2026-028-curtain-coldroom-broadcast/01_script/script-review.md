# 대본·동선 두 차례 검토

검토일 2026-10-11. 대상: 세 본편·세 쇼츠의 작성된 전체 원고와 연출 계획.
현재 TTS·이미지·렌더는 미제작이므로 음성·이미지·완성 영상 통과 기록이 아니다.

## 1차 — 이야기 구조·자연스러운 구술

- 각 편은 강한 첫 문장 뒤 근무 이유·정상 공간을 설명한다. 첫 이상은 단어 수 추정
  44.5 / 47.5 / 48.5초에 위치한다. 실제 음성 뒤 40–60초 구간을 재확인한다.
- 존댓말 구술 종결을 섞고 인사·채널 범퍼·화면 지시 문장을 제외했다.
- 귀신은 흔적→검은 조끼 일부→손·발목 직접 접촉으로 확증한다. 괴물은 흔적→피부
  일부→안전화 접촉·상자 이동으로 확증한다. 학교는 응답 규칙 하나로 위협을 이어 간다.
- 세 이야기의 공간·소품·위협·탈출 방식·잔상은 구별되며 기존 이야기의 결말을 복제하지 않는다.
- 실화가 아닌 창작 표시를 유지했다.
- 쇼츠는 본편 조각을 추출하지 않고 별도 원고로 작성했다. 정체·직접 접촉·탈출·끝의 잔상을 제외했다.

## 2차 — 공간·행동·카메라·글자

- 극장: 줄 왼쪽·창고 오른쪽·뒤 통로 방향, 줄의 고리·커튼 가림, 점검등 스위치·출입문,
  오른손·발목 접촉, 장갑·신발 회수 순서를 대조했다. 멀리 닿는 팔은 의도된 이상으로 기록했다.
- 창고: 선반·비닐막·운반대·옆 통로·출구, 첫/두 번째 상자, 오른쪽 안전화와 탈출 방향을 대조했다.
  장갑을 이미 낀 상태에서 비교하는 혼동을 “한 짝 벗어 놓고 다시 낌”으로 수정했다.
  냉동 구역 기록·카메라 설명의 반복을 줄여 긴장을 유지했다.
- 학교: 잔류 숫자 2→3→4→1, 경비실→교실→현관→정문→편의점→아침, 응답 회피와
  수신 중 화면에서 나는 소리의 의도, 의자 이동·색·다리 수를 대조했다. “목소리가 화면에
  표시됨”을 응답 문구 표시로 고쳤고 이층 복도 불빛이 보이는 위치를 계단 위로 명확히 했다.
- 각 문단에 두 시점의 컷 계획을 연결했다. 같은 장비로 돌아오는 학교 숫자 비교만
  기준 시점을 유지하며 문밖·복도·현관 등 다른 시점과 번갈아 사용한다.
- 집의 사진·기록을 보는 컷은 실제 극장·창고로 돌아간 장면으로 오인하지 않게 프레임·글자를 계획했다.
- 제목·핵심 단서와 전체 나레이션 자막을 분리했다. 실제 정확한 글자는 편집에서 넣는다.
- 전체 원고와 씬의 narration_text/caption_text 일치, 컷 ID·자산 ID·타임라인·소재 종류·쇼츠
  추정 길이는 planning-validation.json의 구조 검사와 함께 확인한다.

판정: 원고·동선·연출 계획은 두 차례 검토 완료. 사용자 대본·스타일·목소리 확인 대기.
생성 후 청취, 모든 개별 이미지 두 검수, 렌더 구간 연속 재생 검수는 별도로 수행한다.
